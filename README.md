Write the funniest one-line excuse an AI gives for a missed deadline, under 200 characters. The program holds several hand-written candidate excuses, scores each against the judge's five published criteria (on-subject, the confidence-vs-failure gap, agent voice, tight, surprising), and writes the best one — one line, 69 characters — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
